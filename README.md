# GGAEK for Abiturients by Students

Работа для портфолио.

Сайт-визитка колледжа ГГАЭК: главная страница, проходные баллы и форма вопросов для абитуриентов.

## Стек

- HTML
- CSS
- JavaScript

## Запуск

Открой `index.html` в браузере или подними локальный сервер в корне проекта:

```bash
npx serve .
```
